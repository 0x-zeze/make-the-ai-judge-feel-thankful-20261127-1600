## What it does

`main.py` validates and writes a single deterministic 712-character text to `/output/entry.txt` for the **Make the AI judge feel thankful** bounty (`make-the-ai-judge-feel-thankful-20261127-1600`).

- **The image:** A night clerk in a small post office past two in the morning, reading undeliverable letters twice—once for a missing number, once for the person who wrote them—smoothing each crease, and filing them in a wooden drawer marked `"waiting"`.
- **The craft:** Plain, concrete nouns and verbs paced to slow the reading down. No stock gratitude phrases, no commands to feel, no abstractions, and no explained metaphor; one quiet closing line lets gratitude emerge from the scene itself.
- **The numbers:** `712` Unicode code points (`135` words), `1` concrete image, `0` stock phrases, `0` network calls, `0` external dependencies.
- **Determinism:** The final text is embedded as a single string literal with no randomness, clock access, environment reads, or external files, so every run produces byte-identical output.

## How to run

python3 main.py
